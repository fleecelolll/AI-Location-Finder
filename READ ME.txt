AI LOCATION FINDER

A little tool I made with AI to estimate real-world locations from screenshots and images locally on 64-bit Windows.

INSTALL

1. Download the latest release ZIP.
2. Extract the complete folder.
3. Double-click Installer.bat.
4. Press Y once to accept the Terms and bundled Tool License and approve setup.
5. Leave the setup window open until every check passes.
6. Double-click the AI Location Finder shortcut created in the folder.

Keep the full extracted folder path at 72 characters or fewer so Windows can install the private packages reliably.

USE

1. Open AI Settings, choose a service and model, and save its API key.
2. Choose one monitor, all monitors, or an image file.
3. Choose the regular-image or GeoGuessr profile.
4. Set the analysis effort and number of checks.
5. Click Find Location and review the result and map.

SETUP DETAILS

Setup keeps official Python 3.14.7, the complete pinned PySide6-Essentials, HTTPX, and AnyIO dependency set, settings, and app-specific files private to this folder. It does not require administrator access, change PATH, or install global Python packages. Downloaded runtime archives and dependency wheels are SHA-256 verified before use. Setup automatically uses the x64 or ARM64 dependency lock and verifies that bundled lock before installation or repair.

Setup creates and validates a folder-local AI Location Finder shortcut that starts the app directly with this folder's private runtime. Run Installer.bat again to repair setup or after moving the complete folder. Saved provider keys and preferences are preserved.

PRIVACY AND REMOVAL

The app has no telemetry, analytics, advertisements, app accounts, or background image uploads. The selected image and analysis context go only to the provider you choose after you start an analysis. The map opens the last layer you selected, or Street on first run, so an online layer may request the currently visible OpenStreetMap or Esri tiles before you start AI analysis. Those map providers do not receive your selected image, AI prompt, or API key. Review setup.log before sharing because it can contain local folder paths.

To remove this tool, close it and delete the extracted folder. This removes its folder-local shortcut, private runtime, dependencies, settings, and app files.

TROUBLESHOOTING

If setup stops, the window immediately names the failed check and shows a
"How to fix it" instruction. The same guidance is saved in setup.log.
Correct the problem and run Installer.bat again. Before downloading large
components, setup checks the bundled source files, offline map, and Windows
shortcut support. It compiles the source before downloading app packages.
Success is shown only after dependencies, offline self-tests, and the
shortcut all pass. Keep the complete extracted folder together.

Street and satellite maps need internet access. The bundled Natural Earth map remains available offline.
