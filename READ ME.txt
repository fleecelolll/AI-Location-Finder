FLEECE AI LOCATION FINDER

A little tool I made with AI to estimate real-world locations from screenshots and images locally on 64-bit Windows.


INSTALL

1. Keep every included file together in the extracted folder.

2. Double click Installer.bat.

3. Let setup finish every check. The first run can take a few minutes.

4. Double click the "AI Location Finder" shortcut that setup creates in this folder.

You can copy that shortcut to your Desktop or pin it to the taskbar. The shortcut launches the app with its own private Python environment.

Keep the extracted folder path at 72 characters or fewer. Run Installer.bat again whenever setup needs repair or after moving the folder to a different location so the shortcut can be refreshed.


UPDATES

Run Installer.bat again to repair or update the private app components. Setup keeps your preferences and Windows-encrypted service keys and recreates the shortcut for the folder's current location.


WHAT THE INSTALLER ADDS

- Uses a compatible 64-bit Python 3.10 through 3.14 already on the PC when possible.

- Otherwise offers to download official Python 3.14.7 privately into this folder.

- Installs pinned PySide6-Essentials and HTTPX components from official PyPI.

- Verifies downloaded private-runtime files with SHA-256 checksums.

- Compiles the app and its provider, prompt, map, and screen-capture modules.

- Verifies Qt network support and the bundled offline map, then runs safe offline self-tests without capturing the desktop or contacting an AI provider.

- Creates a normal double-clickable shortcut for the app.

- Installs one shared per-user Fleece Tools launcher here:

  %LOCALAPPDATA%\Fleece Tools\Python Launcher

- Sets .pyw files to use that shared launcher for your Windows account.

The launcher first looks for .venv\Scripts\pythonw.exe beside the selected .pyw file, then .runtime\python\pythonw.exe beside it. It never uses another tool's private Python.

Before the first Fleece Tools association change, setup exports existing per-user .pyw settings into the shared launcher folder. If setup cannot safely save an existing non-Fleece setting, it stops without overwriting it. If you choose a different .pyw app later, future setup runs leave that newer choice alone.

Setup does not need administrator access, change PATH, install global Python packages, or install a background service.


USE

1. Open AI Settings, choose one of the four direct AI services and an image-capable model, then save the API key for that service.

2. Choose one monitor, All monitors, or an existing image.

3. Choose Regular photo or screenshot or GeoGuessr screenshot.

4. Set the analysis effort and choose one to three AI checks.

5. Choose whether to save a text report after each result.

6. Click Find Location.

7. Review the returned place, coordinates, confidence, evidence, and map pin.

More AI checks normally increase cost and run time. Location results are estimates and can be confidently wrong.


PRIVACY

The app has no telemetry, analytics, advertisements, app accounts, or background image uploads.

The selected image and analysis context are sent only to the AI service you choose and only after you start an analysis. Street and satellite map details require normal online tile requests to OpenStreetMap or Esri. The bundled Natural Earth map works offline. Review the in-app provider privacy note before sending a sensitive image.

API keys and optional guidance are encrypted separately for the current Windows user in:

  .runtime\settings.ini

Reports are saved only when enabled and do not include the source image's full folder path.


TROUBLESHOOTING

If setup fails, check your internet connection and run Installer.bat again. Details are saved in setup.log. The log can include local folder paths, so review it before sharing it.

If the AI Location Finder shortcut does not open, rerun Installer.bat and make sure every final check passes. Setup recreates the shortcut for the folder's current location. Keep the complete folder together.


REMOVE

To remove only AI Location Finder, close it and delete this folder. The app does not add itself to startup, install a Windows service, or create an uninstaller entry. Reports saved elsewhere and map tiles in Windows' application cache remain until you delete them separately.

The shared .pyw launcher can be used by every Fleece Tool, so deleting one tool does not remove it. To restore the .pyw settings that existed before Fleece Tools first changed them, run:

  %LOCALAPPDATA%\Fleece Tools\Python Launcher\Restore pyw association.cmd

The restore helper stops without overwriting a newer non-Fleece choice. After restoring, and after removing every Fleece Tool that uses the launcher, you can delete the shared Python Launcher folder. Its registry backup files can include local program names and paths, so review them before sharing.
